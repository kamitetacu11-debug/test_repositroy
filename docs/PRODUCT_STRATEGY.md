# TaskMaster — Product Strategy & ICP Analysis
## Стратегический анализ целевой аудитории

**Version:** 1.0
**Role:** Senior Product Strategist (B2B SaaS / ERP)
**Date:** November 2024

---

## Executive Summary

TaskMaster позиционируется как **"Lightweight ERP for Task-Driven Teams"** — компактная альтернатива тяжелым ERP-системам для компаний, где ключевой единицей работы является задача, а не процесс.

## 1. Сегменты целевой аудитории

### Сегмент 1: IT-аутсорсинг и Digital-агентства

| Параметр | Описание |
|----------|----------|
| **Размер** | 20–200 сотрудников |
| **Боль** | Хаос в задачах между проектами, невозможность отслеживать продуктивность разработчиков, отсутствие прозрачности для клиентов |
| **Потребность** | Единая система для трекинга задач с метриками производительности и отчетами для клиентов |
| **Почему TaskMaster** | AI-аналитика покажет реальную загрузку команды, геймификация повысит мотивацию разработчиков, KPI дадут объективные метрики |
| **Критичные функции** | Task tracking, Time tracking, KPI dashboards, Team analytics, Client reports |
| **Готовность платить** | $15–30/user/month |
| **Цикл продажи** | 2–4 недели |

---

### Сегмент 2: Розничные сети и франшизы

| Параметр | Описание |
|----------|----------|
| **Размер** | 50–500 сотрудников, 5–50 точек |
| **Боль** | Невозможность контролировать выполнение задач на точках, ручной сбор отчетов, отсутствие единых стандартов |
| **Потребность** | Централизованный контроль задач по всем точкам с мобильным доступом для линейного персонала |
| **Почему TaskMaster** | Mobile-first подход, простой интерфейс для линейного персонала, геймификация для мотивации продавцов, лидерборды между точками |
| **Критичные функции** | Mobile app, Offline mode, Leaderboards, Task templates, Photo reports |
| **Готовность платить** | $8–15/user/month |
| **Цикл продажи** | 4–8 недель |

### Сегмент 3: Производственные компании (дискретное производство)

| Параметр | Описание |
|----------|----------|
| **Размер** | 100–1000 сотрудников |
| **Боль** | SAP/1C слишком сложны для задач, Excel-хаос в планировании, нет связи между офисом и цехом |
| **Потребность** | Простая система задач поверх существующего ERP, без замены основных процессов |
| **Почему TaskMaster** | Не заменяет ERP, а дополняет его. Фокус на задачах, а не на процессах. Быстрое внедрение без интеграций |
| **Критичные функции** | Task dependencies, Gantt-view, Role-based access, Audit logs, API for integration |
| **Готовность платить** | $20–40/user/month |
| **Цикл продажи** | 8–16 недель |

|----------|----------|
| **Размер** | 30–150 сотрудников |

| **Потребность** | Связь клиентских запросов с внутренними задачами, прозрачность для руководства |

| **Готовность платить** | $12–25/user/month |
| **Цикл продажи** | 3–6 недель |

## 8. Заключение

### Ключевые выводы:

1. **Primary ICP:** IT-аутсорсинг и digital-агентства 30-150 человек
2. **Positioning:** "Lightweight ERP for Task-Driven Teams" — между Jira (слишком сложно) и Notion (слишком просто)
3. **Key differentiators:** AI-аналитика + Геймификация + ERP-lite функции
4. **Pricing sweet spot:** $12-25/user/month
5. **Go-to-market:** Product-led growth + Inside sales для компаний 50+
6. **Critical success factors:**
   - Быстрый onboarding (< 10 минут до первой задачи)
   - Mobile-first для полевых сотрудников
   - Импорт из Jira/Asana/Trello
   - ROI, видимый в первую неделю
